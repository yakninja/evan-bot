# evan-bot

Эван - это бот для автоматизации работы группы по переводу "[Пакта](https://pactwebserial.wordpress.com/)". 
Эван отвечает в личных сообщениях, при обращении по имени или через @упоминание,
а также на ответы на свои сообщения. Команды слышит без обращения; если в группе
несколько ботов, можно указать имя бота в команде.
Бот работает только в разрешённых группах и отвечает в личке только разрешённым
пользователям и администраторам; списки ID задаются в локальном `config.py`.

## Разговоры и память

Чтобы продолжить разговор, отвечай на сообщение Эвана через «Ответить» в Telegram.
Бот помнит только выбранную цепочку ответов: соседние ветки и другие чаты в контекст не попадают.
Новое обращение без ответа на сообщение начинает отдельный разговор, в том числе в личке.

По умолчанию в контекст входят до 20 предыдущих сообщений (около 10 обменов),
но не более 16 000 символов. История хранится в SQLite на постоянном Docker-томе
и сохраняется при перезапуске контейнера. Сообщения старше 7 дней не используются
в контексте и автоматически удаляются из локальной истории при запуске, записи
новых сообщений и ежечасной очистке. Это не удаляет сообщения из Telegram.

Память накапливается с момента включения хранения истории. Если старая переписка
ещё не сохранена, бот видит текст сообщения, на которое ты отвечаешь, но не всю прежнюю цепочку.
Лимиты и срок хранения настраиваются через переменные окружения.

Для ответов через OpenAI действуют дневные лимиты: 30 сообщений на пользователя
во всех чатах и 100 сообщений на группу. Счётчики сбрасываются в 00:00 UTC.
Сообщение учитывается один раз, если OpenAI успешно ответил хотя бы на один запрос;
команды, приветствия, ошибки API и другие ответы без успешного запроса не учитываются.

## Команды

- `/help` - помощь по командам
- `/export [название или id главы]` - экспорт перевода главы в текстовый файл для выкладки
- `/stats` - статистика перевода
- `/assign` - назначить переводчиков или редакторов
- `/revoke` - убрать из списка переводчиков/редакторов
- `/executives [название или id главы]` - посмотреть список назначенных
- `/clear_executives [название или id главы]` - очистить список назначенных
- "Эван, глава 1.01" - статус главы, ссылка на редактирование если есть

Команды `assign`, `revoke`, `clear_executives` принимаются только от администрации - пользователей, 
указанных в `config.py` как `ADMIN_USER_IDS` или в старом списке `ADMIN_USERS`.

Также бот может:

- Помочь в нелегком выборе, если его спросить "Эван, А или Б?"
- Отвечать как ему придет в голову, если он не воспринимает обращение как команду

## Разработка

Бот работает как Docker-сервис с Telegram long polling: публичный HTTP-адрес
для получения сообщений не нужен. Для ответов используется OpenAI; история разговоров
не требует отдельного сервера баз данных. Существующие команды перевода используют Smartcat,
а экспорт файлов — S3.

Настройка локального окружения, параметры и тесты описаны в [development.md](development.md).
Секреты задаются в локальных `.env` и `config.py`; эти файлы не входят в Git или Docker-образ.

## Автозамены для выкладки

- `||` - нужен абзац в этом месте перевода
- `<<` - нужно объединить абзацы
